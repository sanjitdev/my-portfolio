# Story: 013-nav

## User Story

**As a** visitor
**I want** a sticky top navigation bar with links to every major section, with scroll-spy highlighting and a mobile hamburger menu
**So that** I can quickly jump to any part of the portfolio

## Acceptance Criteria

- [ ] **Given** the page loads, **When** I scroll past the hero, **Then** the nav bar remains visible at the top of the viewport
- [ ] **Given** the nav renders, **When** I view it on desktop (≥ 768px), **Then** all section links are visible in a row
- [ ] **Given** I scroll to a section, **When** it enters the viewport, **Then** the corresponding nav link is highlighted
- [ ] **Given** I click a nav link, **When** it activates, **Then** the page smooth-scrolls to the corresponding section
- [ ] **Given** I view on mobile (< 768px), **When** I see the nav, **Then** links are hidden and a hamburger button is visible
- [ ] **Given** I click the hamburger, **When** the menu opens, **Then** links appear in an overlay panel; clicking a link closes the menu and scrolls to the section
- [ ] **Given** I click outside the menu or press Escape, **When** the menu is open, **Then** it closes
- [ ] **Given** `prefers-reduced-motion: reduce`, **When** I click a link, **Then** the scroll is instant (no smooth animation)
- [ ] **Given** a section is empty (e.g., Education is empty), **When** the nav renders, **Then** that section's link is NOT shown
- [ ] **Given** the theme toggle is in the nav (per 014), **When** I view the nav, **Then** the toggle is positioned at the right end

## Technical Notes

- Component: `components/nav/TopNav.tsx` (client component, since it needs `IntersectionObserver` and click handlers)
- Use `IntersectionObserver` with a generous rootMargin (e.g., `-40% 0px -55% 0px`) to detect the "active" section
- Smooth scroll: either `scroll-behavior: smooth` in CSS or programmatic `element.scrollIntoView({ behavior: 'smooth' })` with a check for `prefers-reduced-motion`
- Sticky positioning: `sticky top-0 z-50` with a backdrop blur (`backdrop-blur-md`) and translucent background
- Mobile menu: client-side state (`useState`), `aria-expanded` on the hamburger button, `aria-hidden` on the panel
- The nav's list of links is derived from the CV data: only include sections that have content (e.g., skip Education if `education` is empty)
- Use `clsx` for conditional class names

## Edge Cases

| Scenario | Expected Behavior |
|----------|-------------------|
| Hero section is "active" by default | Highlight "Top" or "Home" link in the nav on initial load |
| Two sections are simultaneously in view | Prefer the one higher in the DOM |
| User scrolls faster than observer fires | Acceptable — slight lag in highlight is fine |
| Empty section | Section's nav link is not rendered |
| Click on link to currently-active section | Smooth-scrolls to top of section anyway (no-op visually, no error) |

## Out of Scope

- "Skip to content" link (good a11y practice; add in a future story if needed)
- Search functionality
- Breadcrumbs (single-page site doesn't need them)
